# キーを押し続けたとき、文字の連続入力と打鍵音の回数が違う理由

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

文字キーを長く押すと、macOSやアプリ側で同じ文字が連続入力されることがあります。一方、Klakkの現行入力監視は、押下中キーを記録し、同じキーの反復`keyDown`を新しい物理打鍵として扱わない設計です。

## 1. 一回押す操作を基準にする

キーを押して離す操作を5回繰り返し、文字と音が対応するか確認します。次に一度だけ長押しします。二つを同じテストにしないことが重要です。

## 2. macOSのキーリピート設定を確認する

システム設定にはキーのリピート速度と開始までの時間があります。これは長押し時の文字入力に関係しますが、実際に指を離して再度押した回数とは異なります。

## 3. 音が少ないことを入力漏れと決めつけない

長押しで文字が10個表示され、音が10回鳴らない場合、反復イベント抑制という設計で説明できることがあります。通常の一回ずつの入力で音が欠けるかを別に確認します。

## 4. keyUpが失われた場合の境界

アプリ切替、スリープ、Event Tapの一時停止などで`keyUp`状態を取りこぼすと、押下中の記録が残る可能性があります。Klakkの監視停止時は押下状態を破棄し、再開セッションへ持ち越さないようにしています。

## 5. 再現報告に必要な情報

キー名、長押しか連打か、使用アプリ、入力ソース、外付けキーボードの有無、Klakkを一度無効化して戻した結果を記録します。入力した実際の文章やパスワードは送らないでください。

Klakkが変えるのはMacから追加する音です。実物のキーボードの物理音、スイッチ、重さ、打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
