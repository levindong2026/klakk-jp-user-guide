# 高速入力で打鍵音が重なったとき、音切れと聞き分ける5項目

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

高速で入力すると、短い打鍵音でも前の音が終わる前に次の音が始まります。音が重なる、埋もれる、実際に再生されない、という三つは聞こえ方だけでは区別しにくいため、入力条件を段階的に変えます。

## 1. 一秒に1〜2打から始める

同じ10文字をゆっくり入力し、各キーに音があるか確認します。次に通常速度、最後に最速という順番にします。最初から高速だけを試すと基準がありません。

## 2. 音素材の長さを意識する

低く余韻の長い音は、高い短い音より重なりやすく聞こえます。14種類から性質の違う候補を2つ選び、音量を変えずに比較します。

## 3. Player Nodeの同時発音上限を理解する

Klakkは固定数の`AVAudioPlayerNode`を再利用します。非常に多くの音を同時に要求すると、現在のノード再利用設計に基づく上限があります。すべての入力速度で無制限に独立再生できるとは約束しません。

## 4. 入力漏れは文字側も確認する

画面へ文字自体が入力されていないなら、Bluetoothキーボード、対象アプリ、macOSの入力処理も確認します。文字は入力され、ゆっくりなら音も鳴る場合、速度と音の重なりを中心に切り分けます。

## 5. 録音は補助として使う

画面録音やオーディオ録音で後から波形を確認できますが、録音経路の圧縮やノイズ処理が結果を変えることがあります。実際の出力と録音ファイルを同一視しないでください。

Klakkは実物のキーボードの物理音や打鍵感を変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
