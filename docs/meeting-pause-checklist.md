# オンライン会議の前に打鍵音を止め忘れないための運用チェック

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した利用ガイドです。自社製品へのリンクを含みます。ソフトウェアが追加する音と、実物のキーボードが発する物理音を分けて説明します。

キー入力に同期する効果音は、一人で文章を書くときには作業開始の合図になる一方、オンライン会議や画面共有中は止めたい場面があります。大切なのは、アプリを起動できることよりも「必要な瞬間に確実に止められること」です。

## 1. 会議前に確認するのは出力先だけではない

macOSの出力先にAirPodsやヘッドホンを選んでいれば、Klakkが追加する打鍵音も基本的にその出力先へ送られます。これはKlakkだけの独立ルーティングではなく、ほかのMac音声も通常は同じ出力先へ送られます。また、次の音は別に確認が必要です。

- 実物のキーボードが発する物理音
- 机へ伝わる底打ち音や振動
- マイクが拾う周囲の音
- macOSや会議アプリの通知音
- スピーカーへ切り替わった後の効果音

Klakkは物理キーボードの音を消すアプリではありません。ヘッドホンを使っても、強い底打ちやクリック音をマイクが拾う可能性は残ります。

## 2. 30秒の会議前チェック

1. メニューバーでKlakkが有効か確認する
2. 会議中に不要なら、その場で無効にする
3. macOSの出力先がAirPods、ヘッドホン、スピーカーのどれか確認する
4. 会議アプリのマイク入力先を確認する
5. 一度キーを押し、意図した場所だけから音が出るか確認する
6. 画面共有する場合、設定画面や通知に個人情報が映らないか確認する

会議開始後に気づくより、参加ボタンを押す前の短いルーティンに組み込む方が再現しやすくなります。

## 3. ホットキーは「トグル」だと理解して使う

有効／無効を同じショートカットで切り替える場合、現在の状態を確認せずに押すと、止めたつもりで有効にする可能性があります。

運用では次のどちらかを選びます。

- メニューバーの表示を見てからホットキーを押す
- 会議前はメニューから明示的に無効化する

「押した回数」を覚えるのではなく、現在状態をUIで確認できる方法を使います。ショートカットがほかのアプリと競合していないかも、実際の会議ツールを開いて確認してください。

## 4. AirPodsの再接続後はもう一度出力を確認する

AirPodsをケースへ戻したり、HDMIディスプレイを外したりすると、macOSの既定出力が変わることがあります。会議前後で機器をつなぎ直した場合は、以前と同じ出力先だと思い込まず、次の一音を小さな音量で確認します。

音が出ない場合は、Klakkのオン／オフだけでなく、macOSの現在の出力先、目的のデバイスが接続されているか、会議アプリが独自の出力先を選んでいないかを分けて調べます。

詳しい切り分けは[AirPods・HDMI・USB DACで音が出ないときの確認順序](audio-output-troubleshooting.md)にまとめています。

## 5. 会議後も自動で再開するとは限らない

会議が終わったら、必要なときだけ手動で再び有効にします。会議アプリの終了を検知して自動再開する設計は便利に見えますが、利用者が意図的に止めた状態との区別が必要です。

Klakkでは、利用者が明示的に無効化した機能を、別の状態変化だけで勝手に有効化しないことを重視します。再開後は小さい音量から始め、出力先も確認してください。

## 6. 自分に合う運用だけを残す

打鍵音を作業リズムやASMR的な楽しみとして使えるかどうかには個人差があります。会議のたびに操作が負担なら、勤務時間中は無効、文章を書く時間だけ有効といった単純なルールにします。

Klakkは医療機器ではなく、集中力やADHD症状の改善を目的とした製品ではありません。使わない方が快適なら、停止する判断も正しい利用結果です。
