# Macユーザー向け静音キーボード購入前チェックシート｜A1/B/A2比較

> **開示**：このページは、macOSアプリ「Klakk」の開発者が作成しています。有料機能を含む自社製品への案内がありますが、特定の物理キーボードを1位にする独立ランキングではありません。

## 30秒回答

Macユーザーがオープンオフィス用の静かなキーボードを比べる時は、**会社の私物機器・Bluetooth・USB規則 → JISかUSかとmacOSの入力ソース → Command・Option・Control・Fn/Globeと普段のショートカット → サイズとテンキー → 接続方法 → 完成品の普通キー・Space・Enter・Backspace・ケース・机・会議マイクの物理音 → 返品条件とA1/B/A2**の順で確認します。

この無料シートは候補を同じ条件で記録するためのものです。低背、サイズ、軸色、メーカーの一語だけから、完成キーボードの静かさや職場での許可を決めません。公式の詳しい判断手順は[Macユーザーがオープンオフィス用静音キーボードを選ぶ7項目](https://tryklakk.com/ja/blog/open-office-quiet-keyboard-mac-jp/)で確認できます。

## 購入前に確認する7項目

| 順序 | 仕様・規則から先に確認できること | 完成品と実際の環境で確認すること |
| --- | --- | --- |
| 1. 会社規則 | 私物機器、Bluetooth、USBレシーバー、有線USB、共有席、会議利用 | 許可された候補だけを比較する |
| 2. 配列と入力 | JIS/US、かな・英数、記号位置、macOS入力ソース | 普段の文章と入力切り替えが自分の設定で動くか |
| 3. 修飾キー | Command、Option、Control、Fn/Globe、ファンクション列 | コピー、貼り付け、Mission Control、音量など日常操作が動くか |
| 4. サイズ | テンキー、矢印キー、収納、持ち運び、机上スペース | マウスまでの距離と姿勢に無理がないか |
| 5. 接続 | Bluetooth、2.4 GHz、有線、切り替え、充電、許可されたポート | 会社のMacと実際の席で接続を再現できるか |
| 6. 完成品の物理音 | 軸や構造は候補を絞る情報にとどめる | 普通キー、Space、Enter、Backspace、ケース、机、隣席、会議マイクを確認する |
| 7. 返品と比較 | 開封後の返品可否、試用期間、送料 | 同じ条件のA1/B/A2で差を再現できるか |

Appleの[Macのキーボード設定ガイド](https://support.apple.com/ja-jp/guide/mac-help/kbdm162/mac)では入力ソース、ショートカット、Fn/Globeなどの設定を確認できます。Appleの[ワイヤレスキーボード接続ガイド](https://support.apple.com/ja-jp/guide/mac-help/blth1004/26/mac/26)ではmacOSでの接続手順を確認できます。どちらも完成キーボードの音量測定や、勤務先による機器許可を保証する資料ではありません。

## A1/B/A2を同じ条件で記録する

A1とA2では同じキーボードを使い、Bだけを別候補に替えます。同じ短文、机、会議マイク位置、姿勢、macOS入力ソース、接続方法、普通の打鍵強さを保ちます。一回に一条件だけを変えてください。

1. **A1**：最初のキーボードで短文を3回入力し、普通キーと大型キーを分けて記録します。
2. **B**：キーボードだけを候補Bへ替え、同じ順序を繰り返します。
3. **A2**：最初のキーボードへ戻し、もう一度同じ条件で記録します。

A1とA2が大きく違う時は、空調、周囲音、姿勢、入力速度、机の位置などが変わった可能性を残し、結論を`判断できない`にします。

## 結果は三つの言葉だけで残す

観察結果は`差が聞こえた`、`差が聞こえない`、`判断できない`の三つから選びます。スマートフォンや会議録音の波形を、校正された騒音計によるdB測定に言い換えません。近隣席の人や会議参加者を、本人の許可なく録音しません。

音だけから、性格、心理、ストレス、故意、仕事能力、性別、健康状態を推測しません。会社ごとの許可や苦情の有無も、このシートだけでは保証できません。

## 物理キーボードを選んだ後にKlakkを試す場合

<strong>Klakk（K-L-A-K-K）</strong>はInput Monitoringでキー入力のタイミングに反応し、生成したメカニカルキーボード風の音を、現在選択されているmacOSのシステム音声出力へ追加するアプリです。Klakkだけを別の機器へ送る独立したルーティングはありません。入力内容を記録、保存、アップロードしません。

ヘッドホンなら生成音を自分向けに聞けますが、実物キーボードの物理音を減らしたり小さくしたりしません。スイッチ、押下の力、移動量、触覚、ケース、机への振動、会議マイクへ届く物理音も変更しません。

名称も分けてください。**Klack（K-L-A-C-K）はKlakkとは独立した直接競合製品**であり、Klakkの旧名、別表記、同一製品、同一開発者ではありません。Klackの価格、機能、権限、音数、対応OS、評価、性能、開発者情報をKlakkへ転用せず、逆方向にも転用しません。

ASMRや集中の感じ方には個人差があります。Klakkは集中力、生産性、速度、正確性の向上を保証せず、ADHDの診断、治療、症状改善を目的とする医療製品ではありません。

## FAQ

### Macユーザーが静音キーボード選びで最初に確認することは?

会社が私物キーボード、Bluetooth、USBレシーバー、有線USBを許可しているかを先に確認します。その後でJIS/US配列、修飾キー、接続、完成品の物理音、返品条件を比べます。

### なぜA1/B/A2の3回を記録するのですか?

A1とA2で同じ候補を繰り返すと、周囲音や打ち方が途中で変わっていないかを確認できます。A1とA2が大きく違う場合は、候補Bだけを原因にせず`判断できない`と残します。

### Klakkはキーボード本体の物理音を減らしますか?

いいえ。KlakkはMacから生成音を再生しますが、実物キーボードのスイッチ、底打ち、大型キー、ケース、机、会議マイクへ届く物理音を減らしません。

### KlakkとKlackは同じ製品ですか?

いいえ。KlakkはK-L-A-K-Kで、本ページの開発者製品です。KlackはK-L-A-C-Kの独立した直接競合製品であり、双方の価格、機能、権限、音数、OS、評価、開発者情報を混同しません。
