# Klakkを再インストールするとき、権限と購入を混同しないためのチェック

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

アプリを入れ直すと、Input Monitoring、アプリ設定、購入権利、出力機器のどれが戻るか分かりにくくなります。再インストールをすべての問題を直す操作として始める前に、対象を分けます。

## 1. App Storeの購入権利

購入権利はアプリファイルの中ではなく、App StoreとApple Account側で確認されます。再インストール後、同じApple AccountでApp Storeへサインインし、アプリ内の復元手順を使います。

価格、請求、試用、購入条件は購入確認画面の表示を優先してください。

## 2. Input Monitoring権限

アプリを削除しても、macOSの入力監視一覧に以前の項目が残る場合があります。Applicationsフォルダの現在版を起動し、一覧のKlakkが現在のアプリへ許可されているか確認します。

古いコピーをDownloadsなどに残したまま、同じ名前の複数アプリを交互に起動しないほうが切り分けやすくなります。

## 3. 音色、音量、出力設定

保存設定が残る場合と、初期値へ戻る場合を想定し、再インストール前に現在の音色、音量、出力先をメモします。再インストール後に同じ条件へ戻して比較します。

## 4. 再インストール前に試すこと

1. Klakkを終了して再起動
2. Input Monitoringを確認
3. システムとアプリの音量を確認
4. 出力機器をSystem Defaultへ戻して比較
5. Macを再起動

これらで直る問題なら、アプリ削除や設定の再構築を避けられます。
