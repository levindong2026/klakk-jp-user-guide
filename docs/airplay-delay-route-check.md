# AirPlayへ打鍵音を出す前に確認したい遅延と出力経路

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

HomePod、Apple TV、AirPlay対応スピーカーへMacの音を送ると、ケーブル接続や内蔵スピーカーより遅れて聞こえることがあります。打鍵音はキー操作との時間差が分かりやすいため、音が正常に再生されていても使いにくく感じる場合があります。

## 1. 内蔵スピーカーとの比較から始める

同じ音色、同じアプリ音量で、最初にMacBookスピーカーへ出力します。次にAirPlayへ切り替え、同じ文章を入力します。AirPlayだけ一様に後ろへずれるなら、キー検知の欠落ではなく出力経路の遅延を疑えます。

## 2. すべての音が同じ経路か確認する

macOSのコントロールセンターで現在の出力先を確認します。Klakk以外の音楽や動画も同じ機器から遅れて聞こえるかを比較してください。

複数出力装置やオーディオルーティングアプリを使う場合、Klakkだけでなくシステム全体の構成を記録します。

## 3. 同期用途と操作フィードバックを分ける

AirPlayは部屋で音楽を聞く用途には便利ですが、キーを押した瞬間のフィードバックでは遅延が目立ちます。KlakkのPCM準備が完了していても、ネットワーク転送、受信機器のバッファ、同期処理をゼロにはできません。

## 4. 購入前に実際の部屋で試す

Wi-Fi環境、AirPlay機器、同時に再生するアプリで体感が変わります。3日間の試用中に、普段の入力速度と普段の出力先で確認してください。遅延が気になる場合は、有線ヘッドホン、AirPods、MacBookスピーカーも比較します。

## 製品の範囲

KlakkはMacから追加の打鍵音を再生します。実物のキーボードの物理音、スイッチ、重さ、打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
