# Input Monitoringの許可画面が出ないとき、繰り返しクリックする前に確認すること

> 本稿は有料機能を含むmacOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

入力監視を使うmacOSアプリで「許可」ボタンを押しても、毎回システム設定が開くとは限りません。権限一覧に既に登録されている、以前のアプリ項目が残っている、または変更後に再起動が必要という場合があります。

## 1. システム設定を直接開く

「プライバシーとセキュリティ → 入力監視」を開き、Klakkが一覧にあるか確認します。アプリ内ボタンを何度も押すより、macOS側の現在状態を直接見るほうが確実です。

## 2. スイッチがオンでも機能しない場合

一度オフにしてからオンへ戻し、macOSがアプリの再起動を求める場合はその案内に従います。作業中の文書を保存してから操作してください。

## 3. 同じ名前の古い項目がある場合

アプリを別の場所へ移動した、古いバージョンを残した、または再インストールした場合、以前の項目と見分けにくいことがあります。現在起動しているKlakkを終了し、不要な古い項目を整理してから、Applicationsフォルダの現在版を起動します。

削除対象を確信できない場合は、ほかのアプリの権限をまとめて変更しないでください。

## 4. Accessibilityと混同しない

Klakkの現行実装が確認するのはInput Monitoring側です。「アクセシビリティ」に同名項目があっても、それだけで入力監視の許可を意味しません。

## 5. 許可後に音が出ない場合は出力も確認する

権限が有効でも、Klakkが無効、音量が0、AirPodsが切断、HDMIへ出力、またはシステム全体がミュートなら音は出ません。権限と音声出力を一つの問題として扱わず、順番に確認します。

## 6. 権限を許可する前の判断

Input Monitoringは、ほかのアプリを使っている間にも入力イベントを検知できる強い権限です。用途、保存範囲、外部送信、撤回方法が説明されているか確認してから許可してください。

Klakkはキーが押されたタイミングで音を再生するために権限を使い、入力した文章、パスワード、個々のキーストローク内容を保存・アップロードする設計ではありません。

## 製品の境界

KlakkはMacから追加の打鍵音を再生します。実物のキーボードの物理音や打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
