# JIS配列とUS配列で打鍵音を比べるとき、文字と物理キーを分ける

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

JIS配列とUS配列では、キーの数、ラベル、記号位置、修飾キーの形が異なります。打鍵音を比較するときは、画面へ入力された文字と、押した物理位置を同じものとして扱わないことが重要です。

## 1. 同じ文章だけでは比較条件がそろわない

同じ日本語文を入力しても、かな／英数、記号、変換、Commandの使い方が異なります。まず文字キーだけの短い列、次にSpaceとEnter、最後に修飾キーを含む操作を分けます。

## 2. keyCodeは文字列そのものではない

macOSのキーイベントには物理位置を表すkeyCodeがあります。入力ソースや修飾キーによって画面へ出る文字が変わっても、イベント処理は物理キーを基準にする部分があります。

そのため「この記号を入力したから必ずこの音」と推測せず、使用中の配列で実際に確認します。

## 3. JIS固有キーを確認する

かな、英数、追加された記号キーなど、US配列と対応が一対一でないキーがあります。音が鳴らない、または期待と違う場合は、キー名、配列、macOS入力ソース、再現手順を記録すると問い合わせしやすくなります。

## 4. 左右の修飾キーも別に試す

左右Command、Shift、Option、Controlは物理keyCodeが異なります。一方、集約されたmodifier flagだけでは左右同時押しの全状態を表しにくい場合があります。

## 5. キーボード本体の差を残す

配列だけでなく、キースイッチ、キーキャップ、ケース、机でも物理音が変わります。Klakkを停止した状態と有効な状態の両方を比較します。

Klakkが変えるのはMacから追加する音です。実物のキーボードの物理音、重さ、スイッチ、打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
