# Klakkへ問い合わせる前に作る、個人情報を含めない診断メモ

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開サポートガイドです。自社製品へのリンクを含みます。

音が出ない、権限が戻らない、特定キーだけ違うという問題は、短い再現条件があると確認しやすくなります。一方、入力文章、パスワード、個人ファイル、無関係なシステムログは送る必要がありません。

## 含める情報

```text
macOSバージョン：
Macモデル：
Klakkバージョン：
キーボード：内蔵／USB／Bluetooth
配列：JIS／US／その他
出力先：MacBook／AirPods／USB DAC／HDMI／その他
Klakkの有効状態：
Input Monitoring：オン／オフ
ほかのアプリの音：出る／出ない
再現する最小手順：
Klakk再起動後：
Mac再起動後：
```

## 含めない情報

- 入力した実際の文章
- パスワード、認証コード、秘密鍵
- Apple Accountや決済情報
- 無関係なアプリの画面
- 内容を確認していない大量のログ

## 画面写真を送る場合

権限画面や出力一覧だけに範囲を絞り、氏名、メール、通知、ファイル名、ほかのアプリを隠します。問題と無関係なデスクトップ全体の画像を送らないでください。

## 再現手順は一つずつ

「何をしても鳴らない」ではなく、「MacBookスピーカーでは鳴るが、AirPods再接続後だけ鳴らない」のように差を書きます。設定を変更した順序も含めます。

## 製品の範囲

KlakkはMacから追加の打鍵音を再生します。実物のキーボードの物理音、スイッチ、重さ、打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
