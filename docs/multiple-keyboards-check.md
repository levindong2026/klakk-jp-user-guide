# 内蔵と外付けの2台のキーボードを使うときの打鍵音チェック

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

MacBookの内蔵キーボードと外付けキーボードを交互に使うと、同じKlakkの音でも印象が変わります。ソフトウェアの追加音は同じでも、キーの物理音、手の位置、机への振動が異なるためです。

## 1. 1台ずつ単独で試す

最初に内蔵キーボードだけで30秒、次に外付けだけで30秒入力します。文章、音色、音量、出力先をそろえます。

Klakkを停止した状態も比較し、どの差が実物のキーボード由来かを確認します。

## 2. 交互入力で音量を変えない

外付けの物理音が大きいと、追加音が小さく感じて音量を上げたくなります。しかし内蔵へ戻った瞬間に追加音が大きすぎる場合があります。両方を使う日は、どちらでも不快にならない範囲を選びます。

## 3. 2台同時入力を特殊な機能と考えない

Klakkはキーイベントのタイミングを受け取って音を鳴らします。どちらの物理キーボードから来たかを、すべての場面で利用者向けの別設定として分離する機能ではありません。

別々の音色を自動で割り当てられると推測せず、現在の設定で実際に確認してください。

## 4. Bluetooth再接続も記録する

外付けがBluetoothの場合、スリープ復帰や再接続の直後に最初のキーが接続復帰へ使われることがあります。Klakkだけでなく、文字入力自体がアプリへ届いているか確認します。

## 5. 周囲への物理音を確認する

ヘッドホンへ追加音を送っても、外付けメカニカルキーボードのスイッチ音、底打ち、机への振動は残ります。静かな場所ではKlakkを停止した基準音を先に聞いてください。

Klakkは実物のキーボードの物理音や打鍵感を変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
