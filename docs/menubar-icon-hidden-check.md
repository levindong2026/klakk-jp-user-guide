# Klakkのメニューバーアイコンが見つからないときの確認順序

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

Klakkはメニューバーから有効化、音量、音色、設定、終了を操作するアプリです。アイコンが見えないとき、アプリが終了したとは限りません。ノッチ、画面幅、ほかのメニューバー項目で隠れている場合があります。

## 1. アプリが起動中か確認する

SpotlightまたはApplicationsフォルダからKlakkを一度開きます。既に起動中なら二重起動を作らず、現在のアプリへ戻る動作になることがあります。

アクティビティモニタでKlakkが存在するか確認する方法もあります。強制終了は最後の手段にします。

## 2. 画面幅とノッチ周辺を見る

MacBookのノッチがある画面や解像度を変更した画面では、表示できるアイコン数が減ります。不要なメニューバー項目を閉じる、外部ディスプレイへ切り替える、アプリのウィンドウを閉じてメニュー項目を減らす、という順で確認します。

## 3. フルスクリーンを解除する

フルスクリーンアプリではメニューバーが自動的に隠れる設定があります。ポインタを画面上端へ移動するか、フルスクリーンを解除します。

## 4. 音が鳴っている場合は先に出力を下げる

アイコンが見つからないまま追加音が鳴る場合は、macOSのシステム音量を下げるか、Klakkを終了します。会議中に操作場所を探し続けるより、まず聞こえる音を止めることを優先します。

## 5. 再起動後の状態を記録する

Klakkを終了して再起動し、アイコンが戻るか確認します。ログイン時起動の設定、使用画面、解像度、メニューバー管理アプリの有無を記録すると再現しやすくなります。
