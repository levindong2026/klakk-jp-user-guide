# クラムシェルモードで打鍵音の出力先が変わったときの確認順序

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

MacBookを閉じ、外部ディスプレイとキーボードで使うクラムシェル環境では、画面接続と同時に音声出力先も変わることがあります。Klakkの音が出なくなったように見えても、アプリだけを再起動する前に経路を順番に確認します。

## 1. 外部ディスプレイにスピーカーがあるか

HDMIやDisplayPortは映像だけでなく音声も運べます。macOSがディスプレイを既定出力へ選んでも、ディスプレイにスピーカーがない、音量が0、または別の端子へ音を出す設定なら無音になります。

コントロールセンターのサウンドから現在の出力名を確認し、普段使うヘッドホン、USB DAC、外部スピーカーのいずれかを明示的に選びます。

## 2. システム音で経路を確認する

ブラウザ動画やmacOSの通知音など、Klakk以外の音が同じ出力先から聞こえるか確認します。ほかの音も聞こえないなら、Input Monitoringではなく音声出力側から直すほうが早くなります。

## 3. Klakkの有効状態と音量を確認する

メニューバーのKlakkが無効になっていないか、アプリ内音量が0になっていないかを確認します。出力先を切り替えても、アプリの有効状態が自動で変わるわけではありません。

## 4. 外付けキーボードでもInput Monitoringは同じ

内蔵キーボードから外付けへ変えても、Klakkは文字内容ではなくキーイベントのタイミングを監視します。権限が失われていないか、システム設定の「プライバシーとセキュリティ → 入力監視」で確認します。

## 5. MacBookを開いた状態と閉じた状態を比較する

一度MacBookを開き、同じ出力機器を選んで音を確認します。開閉によってディスプレイやUSBハブの接続状態が変わる場合、再現条件を記録すると切り分けやすくなります。

確認する項目は、電源接続、ディスプレイ接続、USBハブ、出力機器名、Klakkの有効状態の五つです。

## 周囲へ届く音について

ヘッドホンへKlakkの追加音を送っても、外付けキーボードの底打ち、キーキャップ、スイッチ、机への振動は残ります。クラムシェル環境ではキーボードが机へ直接置かれるため、物理音が以前より大きく感じることもあります。
