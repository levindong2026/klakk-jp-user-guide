# AirPodsで打鍵音が遅れて聞こえるとき、入力漏れと遅延を分ける確認手順

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

AirPodsなどのBluetooth機器で打鍵音を聞くと、MacBookのスピーカーより少し遅れて感じることがあります。このとき「キー入力を取りこぼした」と判断する前に、入力イベント、音声再生、無線出力の三つを分けて確認します。

## 1. まずMacBookスピーカーで同じ文章を入力する

Klakkを有効にし、同じ音色と音量のまま30秒ほど入力します。スピーカーではキーと音の対応が自然で、AirPodsに切り替えたときだけ遅く感じるなら、入力監視より出力経路の差を疑えます。

## 2. 「遅れ」と「鳴らないキー」を別々に記録する

遅延は、すべての音がほぼ同じ時間だけ後ろへずれて聞こえる状態です。入力漏れは、特定のキー操作に対応する音が欠ける状態です。

短い文章をゆっくり入力し、次に通常速度で入力します。ゆっくりでも特定キーだけ鳴らない場合は、Bluetooth遅延だけでは説明できません。高速入力だけで音が重なる場合は、再生ノードの同時発音数や音素材の長さも関係します。

## 3. AirPodsのマイク使用中か確認する

会議アプリや録音アプリがAirPodsのマイクを使うと、Bluetoothの音声モードや帯域が変わることがあります。会議を終了した状態と、マイクを使用している状態を分けて比較します。

macOSのコントロールセンターで、出力先だけでなく入力先も確認してください。出力がAirPodsでも、入力はMacBookの内蔵マイクにする運用が合う場合があります。

## 4. 再接続後に出力先を選び直す

AirPodsをケースへ戻して再接続した後、システム既定出力が別の機器へ変わることがあります。Klakkの設定とmacOSの出力先を確認し、同じ名称の機器が複数見える場合は現在接続中のものを選び直します。

## 5. 直ちに「低遅延」と約束しない

Bluetoothの体感遅延は機器、コーデック、OS状態、同時に使うアプリによって変わります。KlakkがPCMを事前準備していても、無線伝送全体の遅延をゼロにはできません。

購入判断では、3日間の試用中に普段のAirPods、普段の入力速度、普段の会議アプリという実際の条件で確認してください。
