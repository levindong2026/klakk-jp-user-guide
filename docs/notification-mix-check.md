# 通知音とKlakkの打鍵音が重なるときの音量確認

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

Klakk、メッセージ通知、カレンダー、ブラウザ動画、音楽は、同じmacOS出力へ混ざることがあります。打鍵音だけを聞いて調整した音量が、通知と重なった瞬間に大きく感じる場合があります。

## 1. 普段の通知設定で試す

テストのためにシステム全体を特殊な音量へ変えるのではなく、普段の作業音量へ戻します。通知が多い時間帯と少ない時間帯の両方で確認します。

## 2. Klakkの音量とシステム音量を分ける

システム音量を下げると、Klakkだけでなく動画や通知も変わります。追加音だけを調整したい場合はKlakk側の音量を使い、何を変えたか一つずつ記録します。

## 3. 集中モードを効果保証にしない

macOSの集中モードは通知の表示や許可を管理する機能です。Klakkが集中モードを有効にするわけではなく、打鍵音で集中力が上がる保証もありません。

通知を減らした状態が必要なら、macOS側で本人が設定し、Klakkあり／なしを同じ条件で比較します。

## 4. 会議前に出力経路を確認する

スピーカーから追加音と通知音が出ると、会議マイクが両方を拾う可能性があります。会議前はKlakkを一時無効化し、会議アプリの通知設定とマイクテストも確認します。

## 5. 不快なら停止を優先する

複数の短い音が重なることで驚く、疲れる、注意がそれる場合は、音量を下げるかKlakkを停止します。特定の音量を医療上安全または集中に最適とは示しません。

Klakkは実物のキーボードの物理音や打鍵感を変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
