# AirPods・HDMI・USB DACで打鍵音が出ないときの確認順序

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した音声出力ガイドです。自社製品へのリンクを含みます。ここで扱うのはMacから再生するソフトウェア音であり、キーボード自体の物理音や打鍵感ではありません。

出力機器を切り替えた直後に音が出ないとき、最初からアプリを再インストールする必要はありません。macOSの出力先、アプリの選択、機器の接続状態を順番に分けて確認します。

## 1. macOS自身の音が出るか確認する

動画やシステムサウンドを短く再生し、選んだ機器から音が出るか確認します。ここで音が出なければ、打鍵音アプリより先にmacOSの「システム設定 → サウンド → 出力」を確認します。

- ミュートになっていないか
- 出力音量が極端に小さくないか
- AirPodsが別の端末へ接続されていないか
- HDMIモニター側の音量が0になっていないか
- USB DACがmacOSの出力一覧に存在するか

## 2. System Defaultか個別指定かを確認する

Klakkの出力先には、macOSの既定出力へ追従する「System Default」と、特定の機器を固定指定する選択があります。

System Defaultを選んだ場合は、macOS側で既定出力を変えるとアプリも次の再生から追従する想定です。個別指定の場合は、保存した機器が切断されると、そのIDが一時的に利用できなくなることがあります。

切り分けのため、一度System Defaultへ戻し、macOS側で目的の機器を既定出力にしてください。これで鳴るなら、個別指定した機器の接続状態を見直します。

## 3. 機器ごとの確認

### AirPods

1. Bluetooth設定で「接続済み」になっているか確認
2. macOSの出力先でAirPodsを選択
3. KlakkをSystem Defaultへ切り替える
4. 一度キーを押して次の音を確認

ケースへ戻した直後や再接続直後は、macOS側の既定出力が先に変わり、アプリ側の次の再生準備が少し遅れる場合があります。短時間に接続・切断を繰り返さず、状態が落ち着いてから一度試します。

### HDMIモニター

HDMIは映像だけでなく音声出力として追加されることがあります。モニターにスピーカーがない、音量が0、または別の音声出力を使っている場合でも、macOSでは選択肢に見えることがあります。ケーブルを抜いた後はSystem Defaultへ戻し、内蔵スピーカーなど現在存在する機器を選び直します。

### USB DAC・オーディオインターフェース

USBハブ経由で認識が不安定な場合は、機器がAudio MIDI設定に表示されるか確認します。サンプルレートやAggregate Deviceを使う高度な構成では、一般的な内蔵出力と同じ挙動を前提にしない方が安全です。まず単一の通常出力で再現するかを切り分けます。

## 4. アプリ側を再起動する前の確認

- メニューバーで再生が停止状態になっていないか
- 選択中のサウンドパックが読み込まれているか
- 出力先一覧に目的の機器が現在も存在するか
- 別の音源では鳴るか

出力先変更では、動作中の音声Engineを停止し、Current Deviceを設定してから再起動する必要があります。Engineが再び動いたことと、希望した機器の設定に成功したことは別なので、「実際にどこから音が出たか」で確認してください。

## 5. それでも鳴らないときに共有する情報

問い合わせ時は、入力した文章や個々のキー内容を送る必要はありません。次の情報だけで切り分けられる場合があります。

- macOSのバージョン
- Klakkのバージョン
- System Defaultか個別指定か
- 機器の種類（AirPods、HDMI、USB DACなど）
- 接続・切断後に起きたか
- macOS自身の音は同じ機器から出るか

個人が付けたAirPods名、会議室名、モニター名には個人情報が含まれる可能性があります。スクリーンショットやログを送る前に伏せてください。

なお、Klakkの打鍵音をASMR的に心地よい、集中のきっかけになると感じるかには個人差があります。音声出力の復旧は医療上の効果を意味しません。Klakkは医療機器ではなく、ADHDの診断、治療、症状改善を目的とした製品ではありません。
