# AirPods・HDMI・USB DACで打鍵音が出ないときの確認順序

> 本稿は有料機能を含むmacOSアプリ「Klakk」の開発者が作成した音声出力ガイドです。自社製品へのリンクを含みます。ここで扱うのはMacから再生するソフトウェア音であり、キーボード自体の物理音や打鍵感ではありません。

出力機器を切り替えた直後に音が出ないとき、最初からアプリを再インストールする必要はありません。機器の接続状態、macOSの出力先、Klakkの出力設定を順番に確認します。公式サイトのMac版では、Klakkの「オーディオ」設定で接続中の出力機器を選べます。

## 1. macOS自身の音が出るか確認する

動画やシステムサウンドを短く再生し、選んだ機器から音が出るか確認します。ここで音が出なければ、打鍵音アプリより先にmacOSの「システム設定 → サウンド → 出力」を確認します。

- ミュートになっていないか
- 出力音量が極端に小さくないか
- AirPodsが別の端末へ接続されていないか
- HDMIモニター側の音量が0になっていないか
- USB DACがmacOSの出力一覧に存在するか

## 2. macOSの現在の出力先を確認する

公式サイトのMac版では、Klakkの「オーディオ」設定の「出力デバイス」で、一覧に表示されるヘッドホンやスピーカーを打鍵音の出力先に選べます。「システムデフォルト」を選ぶと、macOSの既定の出力先に従います。

「システムデフォルト」でAirPodsや有線ヘッドホンを使う場合は、コントロールセンターまたは「システム設定 → サウンド → 出力」で、その機器をmacOSの出力先に選びます。この変更では、動画、通知、音楽など、ほかのMac音声も通常は同じ機器へ送られます。

2026年8月7日の原稿は、macOSの出力先に従う使い方を案内していました。Mac App Store版では、使える設定を実際のアプリ画面で確認してください。出力デバイスの選択項目が表示されない場合は、macOSの現在の出力先を確認します。

## 3. 機器ごとの確認

### AirPods

1. Bluetooth設定で「接続済み」になっているか確認
2. 公式サイトのMac版でAirPodsが一覧にあれば、Klakkの「出力デバイス」で選択。「システムデフォルト」を使う場合はmacOSの出力先でAirPodsを選択
3. 機器の動作を確認する場合は、macOSの出力先にもAirPodsを選び、テスト音や動画を再生
4. 一度キーを押して次の音を確認

ケースへ戻した直後や再接続直後は、macOS側の既定出力が先に変わり、アプリ側の次の再生準備が少し遅れる場合があります。短時間に接続・切断を繰り返さず、状態が落ち着いてから一度試します。

### HDMIモニター

HDMIは映像だけでなく音声出力として追加されることがあります。モニターにスピーカーがない、音量が0、または別の音声出力を使っている場合でも、macOSでは選択肢に見えることがあります。ケーブルを抜いた後は、「システムデフォルト」の場合はmacOSで、Klakkに出力機器を指定している場合はKlakkで、内蔵スピーカーなど現在使える出力先を選び直します。

### USB DAC・オーディオインターフェース

USBハブ経由で認識が不安定な場合は、機器がAudio MIDI設定に表示されるか確認します。サンプルレートやAggregate Deviceを使う高度な構成では、一般的な内蔵出力と同じ挙動を前提にしない方が安全です。まず単一の通常出力で再現するかを切り分けます。

## 4. アプリ側を再起動する前の確認

- メニューバーで再生が停止状態になっていないか
- 選択中のサウンドパックが読み込まれているか
- macOSの出力先一覧に目的の機器が現在も存在するか
- 別の音源では鳴るか

KlakkまたはmacOSで出力先を切り替えた後は、次の打鍵音とほかの音を小さい音量で試し、「実際にどこから音が出たか」で確認してください。接続表示だけでは、現在のシステム出力に選ばれているとは限りません。

## 5. それでも鳴らないときに共有する情報

問い合わせ時は、入力した文章や個々のキー内容を送る必要はありません。次の情報だけで切り分けられる場合があります。

- macOSのバージョン
- Klakkのバージョンと入手元（公式サイトまたはMac App Store）
- Klakkの「出力デバイス」の設定（項目がある場合）
- macOSで現在選ばれている出力先
- 機器の種類（AirPods、HDMI、USB DACなど）
- 接続・切断後に起きたか
- macOS自身の音は同じ機器から出るか

個人が付けたAirPods名、会議室名、モニター名には個人情報が含まれる可能性があります。スクリーンショットやログを送る前に伏せてください。

なお、Klakkの打鍵音をASMR的に心地よい、集中のきっかけになると感じるかには個人差があります。音声出力の復旧は医療上の効果を意味しません。Klakkは医療機器ではなく、ADHDの診断、治療、症状改善を目的とした製品ではありません。
