# 複数ディスプレイ接続時に打鍵音の出力先を固定する考え方

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

2台以上の外部ディスプレイを使うと、HDMIやDisplayPortの音声機器が複数候補として表示されます。画面を主ディスプレイにしたことと、音声の既定出力を選んだことは別です。

## 1. 表示名だけで判断しない

同じ型番のディスプレイを2台接続すると、出力一覧の名称が似る場合があります。片方ずつ音を出し、実際のスピーカーまたは接続先を確認します。

## 2. 主画面と既定出力を分ける

メニューバーがある画面、ウィンドウを置く画面、音を出す機器は独立して選べます。画面配置を変えただけで期待するスピーカーへ自動的に移るとは限りません。

## 3. ケーブルを外した後を確認する

既定出力にしていたディスプレイを外すと、macOSは別の候補へ切り替えます。再接続後も元へ戻らない場合があります。会議や録音の前に毎回現在の出力名を確認します。

## 4. Klakkの設定を一つにそろえる

切り分け中はSystem Defaultを使い、macOS側の経路を確定します。その後、特定デバイス指定が必要なら現在の候補から選び直します。両方を同時に変更しないほうが原因を追いやすくなります。

## 5. スピーカーがないディスプレイもある

macOSが音声デバイスとして認識しても、内蔵スピーカーがない、イヤホン端子だけ、音量0という場合があります。ディスプレイ仕様と本体メニューも確認してください。
