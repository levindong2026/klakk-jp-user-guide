# ログイン時にKlakkを起動した後、最初の一音が出るまでに確認すること

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

「ログイン時に起動」を有効にしても、Macへサインインした直後のすべての機器と権限が同時に準備完了するとは限りません。Klakkの起動、Input Monitoring、AirPods、USB DAC、外部ディスプレイは別々に状態が変わります。

## 1. Klakkのアイコンを確認する

メニューバーへアイコンが表示され、アプリが有効か確認します。ログイン項目へ登録されていても、現在のセッションで起動に失敗した、またはメニューバーの表示領域で隠れている可能性があります。

## 2. 最初はSystem Defaultで確認する

起動直後にAirPodsがまだ未接続なら、システム既定出力はMacBookスピーカーのことがあります。周囲へ音を出したくない場合、ヘッドホン接続を確認してからKlakkを有効にします。

## 3. Input Monitoringの状態を確認する

権限がオフなら、アプリが起動していてもキーイベントを受け取れません。システム設定で許可を確認し、変更後にmacOSが再起動を求めた場合は案内に従います。

## 4. 一度だけゆっくり入力する

メモアプリなどで数文字をゆっくり入力し、文字入力と追加音の両方を確認します。高速入力で最初から試すと、機器接続、キーリピート、音の重なりを混同しやすくなります。

## 5. 自動起動と自動有効化を同じにしない

ログイン時起動は、アプリを開くタイミングの設定です。現在のKlakk有効状態、出力先、音量、権限がすべて期待どおりになる保証ではありません。会議や共有スペースでは毎回メニューバー状態を確認します。

Klakkは実物のキーボードの物理音や打鍵感を変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
