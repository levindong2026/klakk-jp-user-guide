## 「評判」を3種類に分ける

### 1. App Storeの利用者評価

件数、国・地域、投稿日、対象バージョンを確認します。評価件数0の時点では、良い評価も悪い評価も数値から一般化できません。

### 2. 独立した第三者レビュー

実際にKlakk（製品ID `6754638652`）を試したこと、使用したMac、macOS、出力機器、版、日付、提供・広告の有無が分かる記事や動画を別枠で扱います。Klackの画面や製品ページを使う記事はKlakkレビューとして数えません。

### 3. 開発者の一次資料

公式サイト、App Store説明、プライバシーポリシー、この文書は仕様と限界を確認する資料です。開発者の表現を独立した推薦やユーザー口コミとして扱いません。購入前の詳しい確認方法は[Klakkの評判・口コミを購入前に確認する方法](https://tryklakk.com/ja/blog/klakk-reviews-reputation-jp/)にあります。

## レビューで確認する製品境界

- **権限**：Klakkが使うのはmacOSのInput Monitoring（入力監視）で、Accessibilityとは別です。
- **入力内容**：入力した文章、パスワード、個々のキーストローク内容を保存・アップロードしないと説明しています。
- **通信**：Firebase Analytics、StoreKitの購入・復元・権利確認、更新確認などの通信はあり得ます。完全な無通信アプリではありません。
- **音声出力**：macOSで現在選択中のシステム出力を使います。Klakkだけを別の機器へ送る独立ルーティング機能はありません。
- **物理音**：生成音を追加しますが、実物キーボードの物理音、触感、押下圧、ストローク、振動、会議マイクへ届く音は減らしません。
- **ASMR・集中**：心地よさや集中しやすさには個人差があり、生産性、速度、正確性の向上を保証しません。
- **ADHD**：Klakkは医療機器ではなく、ADHDの診断、治療、予防、症状改善を目的としません。

## 口コミがない時の15分確認

1. App StoreでK-L-A-K-K、製品ID `6754638652`、現在の価格と試用条件を照合する。
2. Input Monitoringが必要な理由と、後から取り消す場所を確認する。
3. 低い音量、同じ短文、同じMac、同じ出力先で3種類の音だけを比較する。
4. 文字、Space、Enter、Backspaceの同期、音の重なり、疲れ、停止のしやすさを記録する。
5. ヘッドホンで生成音を聞く場合も、実物キーボードの物理音が残ることを別に確認する。

自分の短時間テストも全ユーザーへの一般的な効果証明ではありません。自分の購入判断のための観察として残します。
