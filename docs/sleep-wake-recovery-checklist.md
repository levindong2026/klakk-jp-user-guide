# Macのスリープ復帰後に打鍵音が出ないときの確認順序

> このページは、有料機能を含むmacOSアプリ「Klakk」の開発者が、現在の実装と利用者向けの確認手順を分けて整理したガイドです。

Macをスリープから復帰したあと、キー入力はできるのに追加した打鍵音だけが鳴らないことがあります。このとき、権限、キーイベント、Audio Engine、出力デバイスを一度に変更すると、どこで止まっていたのか分からなくなります。

以下の順番で、一度に1項目だけ確認してください。

## 1. Klakkが有効なままか確認する

最初にメニューバーを開き、Klakkが有効か確認します。

- 無効なら有効へ戻し、1キーだけ押す
- 有効なら、まだ切り替えず次へ進む

有効／無効を何度も連打すると、元の状態が分からなくなります。最初の状態を覚えておくことが重要です。

## 2. 別の音でMacの出力経路を確認する

ブラウザ動画やmacOSの効果音を短く再生し、現在の出力先から音が聞こえるか確認します。

ここで音が出ないなら、Klakk固有の問題と決めつけず、次を確認します。

- Mac全体の音量が0になっていないか
- AirPodsが「接続済み」だけでなく出力先に選ばれているか
- HDMIディスプレイやUSB DACへ自動で切り替わっていないか
- Bluetooth機器を再接続した直後ではないか

## 3. 入力監視の表示だけで成功と断定しない

「システム設定 → プライバシーとセキュリティ → 入力監視」でKlakkが許可されているか確認します。

ただし、スイッチがオンであることと、現在のEvent Tapへ実際にキーイベントが届いていることは別です。許可表示を見た直後に複数設定を変更せず、Klakkへ戻って1キーだけ試します。

許可を取り消して再び与える場合は、macOSの指示に従い、アプリの再起動が必要かも確認してください。

## 4. Event Tapの状態と音声出力を分けて考える

Klakkの現在の実装では、キーイベント監視と音声再生を別の状態として扱います。

- `CGEventTap` が無効なら、キー入力の通知がアプリへ届かない
- `AVAudioEngine` が停止していれば、通知が届いても音が出ない
- 出力デバイスが変われば、Engineが動いていても想定外の場所から音が出る

「鳴らない」という一つの症状に見えても、確認対象は三つあります。

## 5. 自動ヘルスチェックを待つ場合の限界

現在のKlakkは、有効な間にKeyboard MonitorとAudio Engineを定期的に確認します。Event Tapが無効になっていれば、権限が残っていることを確かめた上で、古いTapとRunLoop Sourceを破棄して作り直します。

ただし、これは「必ず60秒以内にすべて直る」という保証ではありません。

- Timer自体の実行タイミングはmacOSの状態に影響される
- 出力デバイスの選択は利用者の意図と一致するとは限らない
- 権限が取り消されていれば、アプリだけで再付与できない
- 音声素材やEngineの再準備が必要な場合がある

復帰後に急いで使う場合は、自動回復だけを待たず、前後の項目を手動で確認してください。

## 6. 一度だけ無効→有効を試す

権限と出力先が正しいのに音が出ない場合は、メニューバーでKlakkを一度無効にし、数秒待ってから有効へ戻します。

この操作は、監視状態を止めてから再開する境界を作ります。何度も繰り返す必要はありません。1回で変化がなければ次へ進みます。

## 7. 出力デバイスを選び直す

AirPods、HDMI、USB DACを使っている場合は、macOSのサウンド設定で目的の出力先を選び直します。

Bluetooth表示の「接続済み」と、サウンド出力の「選択済み」は同じではありません。スリープ復帰時には内蔵スピーカーへ戻ることもあるため、デバイス名を目で確認します。

## 8. 最後にアプリを再起動する

ここまでの結果を確認してからKlakkを終了し、もう一度起動します。最初から再起動すると一時的に直っても原因を分けられないため、最後の手段にします。

再起動後は次の最小テストだけ行います。

1. Klakkを有効にする
2. 音量を中程度にする
3. 出力先を1つ選ぶ
4. 文字キーを1回押す
5. 修飾キーを1回押す

## 変わらないもの

Klakkが追加するのはMacから再生される音です。次のものは変更しません。

- 実物キーボードのスイッチ
- キーを押す重さや打鍵感
- 底打ち音や机への振動
- 周囲へ届く実物の物理音

macOSの出力先をヘッドホンにするとアプリの追加音を周囲へ流さず聞けますが、ほかのMac音声も通常は同じ出力先へ送られます。Klakkだけを独立して送る機能ではなく、実物のキー音を消すこともできません。
