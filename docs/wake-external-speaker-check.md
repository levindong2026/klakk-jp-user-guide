# スリープ復帰後、外部スピーカーだけ無音のときの確認順序

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

Macのスリープ復帰後、Klakkの設定は残っていても、USBスピーカー、ディスプレイ、Bluetooth機器の接続順が変わることがあります。Klakkだけを原因と決めず、出力経路から確認します。

## 1. 外部スピーカーが一覧にあるか

コントロールセンターのサウンド出力で機器名を確認します。一覧にない場合は、電源、ケーブル、USBハブ、Bluetooth接続を先に直します。

## 2. システム音を再生する

動画や音楽が同じ機器から聞こえるか確認します。すべてのアプリで無音なら、Input Monitoringではなく出力機器側の問題です。

## 3. System Defaultへ戻して比較する

Klakkで特定デバイスを指定している場合、一度System Defaultへ戻します。再接続後の現在の機器を選び直し、同名の古い接続を推測で選ばないようにします。

## 4. 機器側の音量を見る

外部スピーカー、ディスプレイ、USB DACには本体側の音量やミュートがあります。macOSの音量表示だけでは判断できない場合があります。

## 5. 最後にKlakkを再起動する

ほかの音は出る、出力先も正しい、Klakkは有効、Input Monitoringも許可済みという状態で無音なら、Klakkを終了して再起動します。再現する場合は機器名と接続方法を記録します。

KlakkはMacから追加の打鍵音を再生します。実物のキーボードの物理音、重さ、スイッチ、打鍵感は変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
