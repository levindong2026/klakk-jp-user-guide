# 静かなキーボード＋ヘッドホンで打鍵音を楽しむ購入前比較表

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した購入前ガイドです。自社製品へのリンクを含みます。ソフトウェアの打鍵音と、実物のキーボードの音・打鍵感を同じものとして扱いません。

メカニカルキーボードを検討するとき、「クリック音が好き」「入力のリズムを感じたい」という理由が購入のきっかけになることがあります。ただし、音だけが目的なら、最初から複数のキーボードを買う必要があるとは限りません。

一方で、ソフトウェアを使えば実物のキーボードを完全に再現できる、という意味でもありません。購入前に何を変えたいのかを分けると、余計な出費と期待外れを減らせます。

## 先に答え：周囲は静かに、自分だけ生成打鍵音を聞ける？

はい。Macで十分静かな物理キーボードを選び、macOSのシステム出力をヘッドホンへ設定すれば、入力に同期する**生成打鍵音**を自分向けに聞けます。Klakkが担当するのは生成音の追加だけです。実物キーボードのスイッチ音、底打ち、触覚、押下圧、ストローク、机の振動は小さくも変化もしません。

Klakkの正式な綴りは**K-L-A-K-K**、公式ドメインは`tryklakk.com`、Mac App Store製品IDは`6754638652`です。綴りの近いKlackは別製品であり、その機能、価格、レビューをKlakkの説明へ転用できません。現在のKlakkは14種類の生成音を切り替えますが、Klakk単独の独立音声ルーティング、すべてのMacでの「ほぼゼロ遅延」、Spatial Audio、集中力向上を公式保証していません。

この二つの目的を分けた詳しい手順は、Klakk公式の[静かなキーボード＋ヘッドホンで打鍵音を楽しむ方法](https://tryklakk.com/ja/blog/mechanical-keyboard-loud-headphones-mac-jp/)で確認できます。

## ハードウェアとソフトウェアで変わるもの

| 確認項目 | 新しいキーボード | 打鍵音ソフト |
|---|---|---|
| 追加される音色 | スイッチ、キーキャップ、ケース、机などの組み合わせで変わる | 収録済みの音源を切り替えられる |
| 指先の感触 | 荷重、ストローク、反発、底打ち感が変わる | 変わらない |
| 実物の物理音 | 本体の構造に応じて変わる | 消せない |
| 周囲への届き方 | 静音スイッチや吸音材で小さくできる場合がある | macOSの出力先をヘッドホンにすれば追加音を周囲へ流さず聞ける |
| 切り替え | 交換、持ち替え、スイッチ変更が必要 | サウンドパックを選び直せる |
| 持ち運び | 本体の大きさと重さが増える | Mac内で完結する |
| 購入前確認 | 店頭試打や返品条件の確認が必要 | ブラウザ試聴や短期試用ができる |

この表で重要なのは、ソフトウェアが担当できるのは主に「Macから追加して再生する音」だという点です。キーを押した指の感触、キーボード本体の振動、底打ち音、ケースの響きは変わりません。

## 1. 指先の感触を変えたいなら、実物を試す

軽いキー、明確なクリック感、短いストローク、強い反発などを求めているなら、音源を変えるだけでは目的を達成できません。

候補を店頭で試す場合も、数回キーを押すだけでなく、普段の文章を数分入力して確認します。展示台と自宅の机では響き方が違うため、音だけでなく疲れ方、配列、手首の角度、キーの高さも見てください。

## 2. 好きな音の方向だけ知りたいなら、先に試聴する

「高いクリック音と低いコトコト音のどちらが好みか」「連続入力で邪魔にならないか」を知りたい場合は、ブラウザ試聴や打鍵音ソフトが低コストな確認手段になります。

ただし、赤軸、茶軸、青軸などの名前が同じでも、実物の音は一つではありません。キーキャップ、ケース、潤滑、内部フォーム、机、マット、入力の強さ、録音条件によって変わります。ソフトウェアの音源は、特定条件で収録・調整された一つの表現です。

「青軸風の音が好きだったから、同名の実物も必ず同じ音になる」とは考えず、好みの方向を探すための参考にします。

## 3. 周囲を静かにしたいなら、物理音を先に測る

macOSの出力先をAirPodsや有線ヘッドホンにすれば、Klakkが追加する音を周囲へ流さず聞けます。ただし、Klakkだけの独立ルーティングではなく、動画や通知など、ほかのMac音声も通常は同じ出力先へ送られます。実物のキーが出す物理音や机へ伝わる振動も残ります。

静かな職場や夜間の利用では、次の順で確認します。

1. アプリを止めた状態で、キーボード本体の音を聞く
2. 隣の席や部屋の外から、どの程度聞こえるか確認する
3. 必要なら静音キーボード、デスクマット、入力の強さを見直す
4. そのうえで、macOSの出力先をヘッドホンにし、追加音を小さな音量で試す

「ソフトを入れたから周囲が静かになる」のではなく、「追加音をスピーカーから出さない」という限定された効果です。

## 4. 3日間で確認する順序

短期試用では、音源を次々切り替えるより、条件を固定して比較します。

### 1日目：音を選ぶ

- ブラウザ試聴で苦手な音を除外する
- アプリでは小さい音量から始める
- 文章作成、コーディングなど普段の作業で30分使う

### 2日目：環境を変える

- MacBook内蔵キーボードと外付けキーボードで比較する
- AirPodsとスピーカーで出力先を切り替える
- アプリを停止し、実物のキー音だけでも確認する

### 3日目：使わない場面を確認する

- オンライン会議前にすぐ停止できるか
- 集中したい作業で、途中から音が邪魔にならないか
- AirPodsを再接続した後、意図した出力先になるか

気持ちよさだけでなく、「停止しやすいか」「使わない方が快適な場面があるか」も購入判断に含めます。

## 5. Input Monitoringの説明も確認する

Macでほかのアプリを使っている間にもキー操作へ反応するには、Input Monitoring（入力監視）権限が必要です。音が好みでも、権限とデータの説明に納得できなければ利用しない判断ができます。

Klakkはキーの押下・解放と物理キーコードを端末上で処理し、対応する音を選びます。入力した文章、パスワード、個々のキーコードやキー操作の並びを保存・送信する設計ではありません。アプリ起動、設定、権限状態、サウンドパック、一定単位にまとめた利用回数などの解析イベントとは分けて扱います。

最新の範囲は[日本語プライバシーポリシー](https://tryklakk.com/ja/privacy/)で確認してください。

## 結論：変えたいものに合わせて選ぶ

- **指先の感触、配列、本体の物理音を変えたい**：実物のキーボードを試す
- **好きな音の方向を低コストで比べたい**：ブラウザ試聴から始める
- **追加音を周囲へ流さず楽しみたい**：macOSのヘッドホン出力を試す
- **部屋を静かにしたい**：キーボード本体と机の物理音を先に見直す
- **複数の音を切り替えたい**：ソフトウェアの試用で運用を確認する

Klakkは医療機器ではなく、集中力やADHD症状の改善を目的とした製品ではありません。ASMRや聴覚フィードバックの感じ方には個人差があります。
