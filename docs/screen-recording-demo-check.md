# 打鍵音アプリの比較動画を録る前に、録音経路を確認する6ステップ

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

「Klakkなし」と「Klakkあり」を比較する動画では、聞こえた差がアプリの追加音なのか、実物のキーボード音なのかを説明できるようにします。録画ソフトの設定によっては、システム音を録らずマイク音だけを収録するためです。

## 1. 比較したい音を先に決める

次の三つを分けます。

- Macから再生されるKlakkの追加音
- 実物のキーボードが出す物理音
- 部屋、机、マイク位置による環境音

一つの動画で全部を完全に再現しようとせず、「システム音だけ」「マイク録音」「実際の使用感」のどれを示すか明記します。

## 2. 画面収録がシステム音を含むか確認する

macOSの標準機能や使用する録画アプリで、システム音声の収録方法が異なります。10秒のテストを行い、Klakkの追加音が完成ファイルに入っているか再生して確認します。

## 3. マイクを使う場合は位置を固定する

マイクをキーボードへ近づけると物理音が大きくなり、視聴者の実環境より強調されることがあります。距離、机、キーボード、入力の強さを記録し、比較の途中で変えません。

## 4. 同じ文章と入力速度を使う

比較前後で文章、キーの種類、入力速度をそろえます。SpaceやEnterは文字キーと音素材や物理構造が異なるため、特定キーだけの印象で全体を判断しないようにします。

## 5. 音量の後処理を開示する

録画後にノーマライズ、コンプレッサー、ノイズ除去、EQを使った場合は、その事実を説明に書きます。加工済み動画の音量を、そのままMacで再生される音量と扱わないためです。

## 6. ヘッドホン運用の限界を入れる

macOSの出力先をヘッドホンにすれば、Klakkの追加音を周囲へ流さず聞けます。ただし、Klakkだけを別の機器へ独立して送る機能ではなく、ほかのMac音声も通常は同じヘッドホンへ送られます。キーキャップ、スイッチ、底打ち、机への振動も消えません。比較動画でも、ソフトウェアが実物のキーボードを静音化するように見せないことが重要です。

## 視聴者が自分で確認できる導線

動画の録音環境と視聴者の環境は一致しません。購入前にブラウザ試聴を案内し、App Store版の試用で本人の出力機器とキーボードを確認できるようにします。

Klakkは実物のキーボードの物理音、スイッチ、重さ、打鍵感を変えません。ASMRや集中の感じ方には個人差があり、ADHDを含む症状を診断、治療、改善する医療製品ではありません。
