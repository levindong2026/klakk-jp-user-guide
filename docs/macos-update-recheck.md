# macOSアップデート後にKlakkを確認する8項目

> 本稿は有料macOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

macOSの更新後は、ログイン項目、Input Monitoring、音声出力、Bluetooth機器の状態が以前と同じとは限りません。音が出ない場合も、設定を一度に全部変えず順番に確認します。

## 更新後チェック

1. Klakkが起動しているか
2. メニューバーで有効になっているか
3. Input Monitoring一覧にKlakkがあり、許可がオンか
4. macOSとKlakkの音量が0でないか
5. 現在の既定出力が期待する機器か
6. AirPods、USB DAC、外部ディスプレイが再接続されているか
7. ログイン時起動を使う場合、システム設定のログイン項目にも状態が反映されているか
8. 一度アプリを終了して再起動しても同じか

## 権限をまとめて初期化しない

問題がKlakkだけにあるか分からない状態で、すべてのプライバシー権限を削除したり、ほかのアプリの許可を変更したりしないでください。現在状態を記録し、対象を一つずつ確認します。

## 出力機器の再選択

OS更新後に同名の機器が一覧へ戻っても、内部の接続状態が更新される場合があります。System Defaultを一度確認し、特定機器を指定している場合は現在の候補から選び直します。

## 問い合わせに含める情報

macOSバージョン、Klakkバージョン、Macモデル、出力機器、権限画面のオン／オフ、ほかの音が出るかを記載します。入力文章、パスワード、不要なシステムログは送らないでください。
