# USB DACを抜き差しした後に打鍵音が出ないときの7項目

> 本稿は有料機能を含むmacOSアプリ「Klakk」の開発者が作成した公開ガイドです。自社製品へのリンクを含みます。

USB DAC、オーディオインターフェース、USBスピーカーを抜き差しした後は、機器名が同じでもmacOS内部の接続状態が更新されます。Klakkの音が出ないときは、次の順番で確認します。

## 1. 機器がmacOSに認識されているか

「Audio MIDI設定」またはコントロールセンターの出力一覧に機器名があるか確認します。一覧にない状態では、Klakkからその機器を選び直しても再生できません。

## 2. USBハブを外して直接接続する

給電不足やハブの再認識待ちを切り分けるため、可能ならMacへ直接接続します。別のUSBポートでも同じか確認します。

## 3. macOSの既定出力を確認する

機器を外したときにMacBookスピーカーへ戻り、再接続後もそのままになる場合があります。システム既定を使う設定なら、Klakkも現在の既定出力に従います。

## 4. 機器側の音量とミュートを確認する

USB DACには本体ノブ、ミュート、出力切替がある場合があります。Mac側の音量が操作できない機器では、本体側の状態が特に重要です。

## 5. ほかのアプリで音を出す

音楽や動画が聞こえるか確認します。すべてのアプリで無音なら、Klakk固有の入力監視より先に出力機器の経路を直します。

## 6. Klakkの出力設定を選び直す

保存されているデバイスIDと再接続後のIDが一致しない場合を想定し、出力候補を開いて現在の機器を選び直します。同名機器を推測だけで選ばず、実際に一音ずつ確認します。

## 7. 最後にKlakkを再起動する

機器が認識され、ほかの音も出ているのにKlakkだけ無音なら、アプリを終了して再起動します。再起動前に有効状態、音量、Input Monitoring権限を記録すると、原因を混ぜずに確認できます。

## 製品の範囲とプライバシー

KlakkはInput Monitoring権限を使い、キーが押されたタイミングでローカルの音を再生します。入力文章やパスワードを保存・送信する目的ではありません。詳細はプライバシーポリシーを確認してください。

ソフトウェアが変えるのはMacから追加する音です。実物のキーボードの物理音、スイッチ、重さ、打鍵感は変えません。集中やASMRの感じ方には個人差があり、ADHDを含む症状の診断、治療、改善を目的とした医療製品ではありません。
